edclient¶

Aplicación de escritorio para conectar, volar, ver telemetría, ajustar y actualizar los drones. Funciona con el firmware S2 y el S3; con el S2, lo que no existe se muestra como "—".

Instalación¶

git clone -b espnow-only https://github.com/juliordzcer/espdrone-lib-python.git
git clone -b espnow-only https://github.com/juliordzcer/espdrone-clients-python.git
pip install -e espdrone-lib-python
pip install -e espdrone-clients-python
edclient

La ventana¶

  • Barra superior: selector de dron, Buscar, Conectar y pastillas de estado:
  • enlace (RSSI), batería, estimador, controlador;
  • carga de CPU de cada núcleo y tiempo del lazo.

A la derecha, STOP. - Pestañas: se muestran u ocultan en Ver → Pestañas. - Tema: Ver → Tema, claro u oscuro.

Pestañas¶

Pestaña Para qué
Panel Vista general: horizonte artificial, posición y velocidad, altura en el tiempo, estado, motores, batería y Armar
Vuelo Vuelo con mando: modo asistido, trims, estimador, consignas, estimados, motores y empuje
Simulador Entrenador de vuelo (ver página)
Vista 3D Pose en 3D de uno o varios drones
Sistema Carga por núcleo, lazo, memoria, enlace ESP-NOW, sensores; identificar, recalibrar o borrar la configuración
Parámetros Todos los parámetros: editar, guardar en la NVS, exportar y cargar
Ajuste Ganancias de los controladores con sliders
Gráficas Gráficas en tiempo real de cualquier bloque de log
Bloques de log / Variables de log Definir bloques y ver todas las variables disponibles
Registro de vuelo Estado, descarga a CSV, guardar en la flash y opciones de grabación (solo S3)
Consola Mensajes del firmware y pruebas de hélices y batería
Log del cliente Mensajes internos de edclient para depurar

Mando¶

  1. Conecta el mando y elígelo en el menú Control.
  2. Control → Configurar mando… para asignar ejes y botones.
  3. En Vuelo, elige el modo asistido: Mantener altura o Mantener posición.

Preferencias¶

Archivo → Preferencias (Ctrl+,):

Opción Efecto
Pestaña al iniciar Pestaña que se abre al arrancar
Conectar al último dron Se conecta solo si aparece en la búsqueda
Pedir confirmación antes de armar Diálogo de confirmación en Panel y Vuelo
Refresco de datos 5, 10 o 20 Hz para los logs de la pestaña Vuelo
Puerto serie / Canal Wi-Fi Fijar el gateway o el canal en lugar de detectarlos

Actualizar el firmware¶

Conexión → Actualizar firmware:

  • Por USB (esptool): para la primera vez o si cambian las particiones.
  • Sin cable (OTA por ESP-NOW): al dron conectado.

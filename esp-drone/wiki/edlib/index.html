edlib¶

Librería Python para controlar los drones desde scripts: es la base de edclient y de los scripts del repositorio de firmware. Compatible con el S2 (protocolo V1) y el S3 (protocolo V2); la versión se negocia sola al conectar.

Instalación¶

git clone -b espnow-only https://github.com/juliordzcer/espdrone-lib-python.git
pip install -e espdrone-lib-python

URI¶

espnow://<mac del dron>?ch=<canal Wi-Fi>[&port=/dev/ttyACM0]
Variable de entorno Uso
EDLIB_ESPNOW_PORT Puerto serie del gateway
EDLIB_ESPNOW_CH Canal por defecto si la URI no lo trae

Varios drones comparten un mismo gateway: abre un EspDrone por URI.

Ejemplos¶

Buscar drones¶

import edlib.edtp

edlib.edtp.init_drivers()
print(edlib.edtp.scan_interfaces())   # [['espnow://ecda3be30da2?ch=11', 'ESP-Drone'], ...]

Parámetros¶

from edlib.espdrone import EspDrone
from edlib.espdrone.syncEspDrone import SyncEspDrone

URI = 'espnow://ecda3be30da2?ch=11'
with SyncEspDrone(URI, cf=EspDrone(rw_cache='./cache')) as scf:
    scf.cf.param.set_value('stabilizer.estimator', '5')

Telemetría¶

from edlib.espdrone.log import LogConfig
from edlib.espdrone.syncLogger import SyncLogger

conf = LogConfig(name='Pose', period_in_ms=50)
for var in ('stateEstimate.x', 'stateEstimate.y', 'stateEstimate.z'):
    conf.add_variable(var, 'float')

with SyncEspDrone(URI, cf=EspDrone(rw_cache='./cache')) as scf:
    with SyncLogger(scf, conf) as logger:
        for timestamp, data, _ in logger:
            print(timestamp, data)

Vuelo con el commander de alto nivel¶

import time

with SyncEspDrone(URI, cf=EspDrone(rw_cache='./cache')) as scf:
    scf.cf.platform.send_arming_request(True)
    hl = scf.cf.high_level_commander
    hl.takeoff(0.5, 2.0)
    time.sleep(3)
    hl.go_to(0.5, 0.0, 0.5, 0.0, 2.0)
    time.sleep(3)
    hl.land(0.0, 2.0)
    time.sleep(3)

Pose externa (captura de movimiento)¶

scf.cf.extpos.send_xy_yaw(x, y, yaw_rad)           # x, y [m] y yaw [rad]; z la mide el ToF
scf.cf.localization.send_emergency_stop()          # paro

Módulos¶

Módulo Para qué
espdrone.commander Consignas: actitud, velocidad (mundo o cuerpo), altura, posición, paro
espdrone.high_level_commander Despegue, aterrizaje, go_to, trayectorias
espdrone.param / espdrone.log Parámetros y telemetría
espdrone.syncEspDrone / syncLogger Uso síncrono en scripts
espdrone.platformservice Armado y recuperación tras choque
espdrone.localization / extpos Pose externa y paro de emergencia
espdrone.mem Subir trayectorias
espdrone.flog Registro de vuelo del S3
espdrone.ota Actualizar firmware por ESP-NOW
utils.param_io Exportar e importar parámetros

Scripts del firmware¶

El repositorio de firmware trae scripts listos en scripts/: diagnóstico (edlib/diag_gyro.py), motores, parámetros, registro de vuelo, identificación de sistemas (sysid/), vuelo, enjambre y posicionamiento.

Compilar y flashear¶

Requisitos¶

  • ESP-IDF 6.x (se desarrolla sobre 6.1) con el target esp32s3.
  • Python 3.10 o superior, Git y Linux o macOS.
git clone --recursive https://github.com/espressif/esp-idf.git ~/esp/esp-idf
cd ~/esp/esp-idf
./install.sh esp32s3

Obtener el código¶

git clone -b hw/s3-v1.3 --recursive https://github.com/juliordzcer/esp-drone.git
cd esp-drone

--recursive trae también edlib y edclient (libs/).

Compilar¶

. ~/esp/esp-idf/export.sh
idf.py build

Pruebas de host: compilan el código real del firmware para el PC y no necesitan ESP-IDF.

make -C test

Flashear¶

La primera vez, y cada vez que cambie partitions.csv, flashea por USB (USB nativo del ESP32-S3):

idf.py -p /dev/ttyACM0 flash monitor

Después puedes actualizar sin cable, por ESP-NOW, desde edclient: Conexión → Actualizar firmware, con el dron conectado.

Tip

No lances edclient desde la misma terminal en la que cargaste export.sh: el Python de ESP-IDF no trae PyQt6.

Particiones¶

Partición Tamaño Uso
nvs 64 KB Parámetros persistentes, bias del acelerómetro, historial de batería
otadata, ota_0, ota_1 2 × 4 MB Dos imágenes de firmware para actualizar por OTA y volver atrás si falla
flog 6 MB Copia del último registro de vuelo, que sobrevive a apagar el dron

Borrar la configuración¶

Pon system.nvsReset = 1 (desde edclient: Sistema → Borrar configuración guardada). El dron borra toda la NVS y se reinicia con los valores por defecto.

Gateway ESP-NOW¶

El gateway es un ESP32 conectado al PC por USB. Traduce entre el puerto serie y ESP-NOW, y permite hablar con varios drones a la vez sin router ni WiFi.

Repositorio: espnow-gateway.

Placas soportadas¶

Placa Conexión Notas
ESP32-S3 Super Mini (recomendada) USB nativo TX a 20 dBm, antena integrada
Devkit ESP32 UART0 por el CH340 A 921600 baudios

En planes: XIAO ESP32-S3 con antena externa, botón físico de STOP, LEDs, buzzer y una PCB propia.

Compilar y flashear¶

Con ESP-IDF cargado:

git clone https://github.com/juliordzcer/espnow-gateway.git
cd espnow-gateway
# ESP32-S3 Super Mini
idf.py -B build-s3 -D SDKCONFIG=sdkconfig.esp32s3 set-target esp32s3 build   # aplica sdkconfig.defaults.esp32s3 solo
idf.py -B build-s3 -p /dev/ttyACM0 flash
# Devkit ESP32
idf.py build && idf.py -p /dev/ttyUSB0 flash

Cómo funciona¶

  • Búsqueda: el gateway manda un discover en los canales 1 a 13. Los drones responden con su nombre y su canal, y edlib arma las URI espnow://<mac>?ch=<canal>.
  • En vuelo: el gateway se queda en el canal de los drones y reenvía cada paquete EDTP al dron por su MAC. Los peers se crean solos y se reemplazan por antigüedad.
  • Estado: el comando INFO devuelve la MAC, el canal, la versión y los contadores de envío, recepción y pérdidas. (La pestaña Sistema de edclient muestra la señal y las pérdidas vistas desde el dron.)

Trama serie¶

A5 5A len type body[len-1] crc8        (crc8 polinomio 0x07 sobre type + body)
Tipo Dirección Contenido
0x01 TX PC → gateway mac[6] + payload
0x02 SET_CH PC → gateway canal
0x03 INFO PC → gateway sin cuerpo
0x04 SCAN PC → gateway tiempo por canal / 10 ms
0x81 RX gateway → PC mac[6] rssi canal payload
0x83 INFO gateway → PC mac, canal, versión y contadores (u32 LE)
0x84 SCAN_DONE gateway → PC canal

Primeros pasos¶

Lo que necesitas¶

  • Un dron ESP-Drone S3 con batería 1S cargada.
  • Un gateway ESP-NOW (ESP32-S3 Super Mini o devkit ESP32) con su firmware y un cable USB.
  • Un PC con Linux (recomendado) y Python 3.8 o superior.
  • Opcional: un mando compatible con el sistema (USB o Bluetooth).

1. Instalar edlib y edclient¶

git clone -b espnow-only https://github.com/juliordzcer/espdrone-lib-python.git
git clone -b espnow-only https://github.com/juliordzcer/espdrone-clients-python.git
pip install -e espdrone-lib-python
pip install -e espdrone-clients-python

Agrega tu usuario al grupo dialout para acceder al puerto serie del gateway y vuelve a iniciar sesión:

sudo usermod -aG dialout $USER

2. Aprender en el simulador¶

Antes de volar el dron real, practica en el simulador:

edclient

Abre Ver → Pestañas → Simulador, elige el ejercicio Primeros pasos (guiado) y sigue las instrucciones en pantalla. Cuando domines el estacionario y el aterrizaje de precisión en modo Altura asistida, pasa al dron real.

3. Conectar el dron¶

  1. Conecta el gateway por USB.
  2. Enciende el dron sobre una superficie nivelada y no lo muevas: al arrancar mide el bias del giroscopio y pita al terminar.
  3. En edclient pulsa Buscar, elige el dron y pulsa Conectar.
  4. La barra superior se llena: enlace, batería, estimador, controlador, CPU y lazo.

Si no aparece ningún dron, revisa Problemas frecuentes.

4. Primer vuelo¶

  1. Elige el mando en el menú Control.
  2. En Vuelo elige el modo asistido Mantener altura.
  3. Arma el dron con el botón Armar (Panel o Vuelo) y sube el empuje poco a poco.
  4. Ten siempre a mano STOP (barra superior): corta los motores y bloquea el dron hasta reiniciarlo.

Seguridad

Vuela sin personas cerca y con protectores de hélices. Si deja de recibir consignas, el dron se nivela a los 0.5 s y corta motores a los 2 s; con batería baja aterriza solo. Aun así, STOP es la última palabra (ver Seguridad).

Problemas frecuentes¶

Síntoma Causa probable
"Ningún dron encontrado" Gateway sin firmware, otro programa usando el puerto serie, o dron apagado. Prueba EDLIB_ESPNOW_PORT=/dev/ttyACM0 edclient
edclient no arranca: falta PyQt6 La terminal tiene activado el entorno de ESP-IDF; abre otra
El dron no arma Está volcado, un sensor falló en el arranque o quedó bloqueado tras un STOP (reinícialo)
El simulador no responde al mando Hay un dron conectado: el mando controla el dron real. Desconéctalo
